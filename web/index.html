VAERS Vaccine Lot Report Explorer

Descriptive summaries of reports by vaccine lot — browser-only, no account or server upload.

Reporting counts are not safety rates or evidence of causation. VAERS contains unverified adverse-event reports after vaccination. This tool has no administered-dose denominator, background comparison, or statistical signal test. Large counts can reflect vaccine use or reporting patterns. Do not rank lots by safety using these results.

1. Select VAERSVAX CSV

Download VAERS data from the official VAERS data portal. Select the VAERSVAX.csv vaccine table, not the VAERSDATA table.

Required fields: VAERS_ID, VAX_LOT. Optional: VAX_TYPE, VAX_MANU. Whitespace/case in lot labels is normalized; empty or unknown lots are excluded. Repeated IDs within a lot are counted once. A single report associated with multiple lots may be included in multiple groups.

Only aggregate lot-level counts are displayed/exported; the original file stays in browser memory. Avoid uploading private patient data; public datasets may still include sensitive free text.
